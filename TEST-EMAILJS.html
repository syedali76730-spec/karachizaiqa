📧 EmailJS Test Tool

⚠️ DELETE THIS FILE AFTER TESTING!
This tool helps diagnose EmailJS configuration issues.
Where to find these values in EmailJS:
• Service ID: Email Services → Click your service → Copy ID
• Template ID: Email Templates → Click template → Copy ID
• Public Key: Account → General → Public Key

Step 1: Enter Your EmailJS Credentials

Common 400 Error Causes:

  1. Wrong Public Key: Make sure you copied the ENTIRE key
  2. Wrong Service ID: Check it matches exactly (case-sensitive)
  3. Wrong Template ID: Each template has its own ID
  4. Template variables missing: Make sure template has all required variables
  5. EmailJS account inactive: Verify email in EmailJS account
Once you get it working:
1. Copy the working IDs
2. Update them in your index.html file
3. DELETE THIS FILE!
